Name

fcli-tool-sc-client - Manage ScanCentral SAST Client installations.

{% raw %}

Synopsis

fcli tool sc-client [-h] [COMMAND]

Description

Generic fcli options (also see documentation link below)

-h, --help

Use 'fcli [command] -h' to display help for fcli (sub-)commands.

Commands

install

Download and install ScanCentral SAST Client.

list, ls

List available and installed ScanCentral SAST Client versions.

list-platforms, lsp

List available platforms for ScanCentral SAST Client.

get

Get information about a specific ScanCentral SAST Client version.

register

Register an external ScanCentral SAST Client installation.

run

Run ScanCentral Client.

uninstall

Uninstall ScanCentral SAST Client.
