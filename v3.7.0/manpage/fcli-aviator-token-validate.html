Name

fcli-aviator-token-validate - Validate an access token for a user.

Synopsis

fcli aviator token validate -t=source [[-h] [--env-prefix=<envPrefix>] [--log-file=<logFile>] [--log-level=<logLevel>] [--log-mask=<logMaskLevel>] [--debug]] [[--admin-config=<configName>]] ] [--style=<outputStyleElements>_[, <outputStyleElements>…​]]…​ ] [--to-file=<outputFile>_]]

Description

Validates an existing access token for a user within an Aviator tenant, checking its authenticity and status. Requires the user’s email, the token value, tenant name, and a private key for signing the request.

Options

-t, --token=source

Aviator user access token. Can be specified as one of:

file:<local file containing token>
string:<token string value>
env:<env-var name containing token>
If no prefix is given, <local file> is assumed.
For security reasons, avoid specifying sensitive tokens directly
on the command line (using string:). Prefer using files or env:.

Aviator administrator configuration name options

--admin-config=<configName>

Name of the Aviator administrator configuration to use. Default value: default.
