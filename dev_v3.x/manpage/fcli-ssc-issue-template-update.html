Name

fcli-ssc-issue-template-update - Update an issue template.

{% raw %}

Synopsis

fcli ssc issue-template update [--set-as-default] [-d=<description>] [-n=<name>] [--add-tags=<tagSpecs>[, <tagSpecs>…​]]…​ [--rm-tags=<tagSpecs>[, <tagSpecs>…​]]…​ [[-h] [--env-prefix=<prefix>] [--log-file=<logFile>] [--log-level=<logLevel>] [--log-mask=<level>] [--debug]] [[--ssc-session=<sessionName>]] [[-o=<type+args>] [--style*=<style>,…​]…​ ] [--to-file=<outputFile>_]] <issueTemplateNameOrId>

Description

Options

--add-tags=<tagSpecs>[,<tagSpecs>…​]

Comma-separated list of custom tag names or GUIDs to add.

-d, --description=<description>

Update issue template description.

-n, --name=<name>

Update issue template name.

--rm-tags=<tagSpecs>[,<tagSpecs>…​]

Comma-separated list of custom tag names or GUIDs to remove.

--set-as-default

Set this issue template as the default issue template.

SSC session name options

--ssc-session=<sessionName>

Name of the SSC session to use for executing this command. Default value: default.

Write output to the specified file.
