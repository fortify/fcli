Name

fcli-aviator-token - Manage Aviator access tokens.

Synopsis

fcli aviator token [-h] [COMMAND]

Description

Commands for creating, deleting, revoking, listing, and validating Aviator access tokens for users within a specified tenant.

Options

-h, --help

Show this help message and exit. Use 'fcli <command> -h' to display help for subcommands.

Commands

create

Create an access token for a user.

delete, rm

Delete an access token for a user.

list, ls

List access tokens for a user.

revoke

Revoke an access token for a user.

validate

Validate an access token for a user.
