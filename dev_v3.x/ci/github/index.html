v3.1.x

OpenText Application Security (Fortify Software Security Center)

  • fortify/github-action
    Run OpenText Application Security Testing (AST) scans in GitHub Actions workflows

  • fortify/github-action/with-github-artifacts
    Run OpenText AST scans and upload debug artifacts to GitHub.com artifact storage

  • fortify/github-action/with-ghes-artifacts
    Run OpenText AST scans and upload debug artifacts to GHES-compatible artifact storage

  • fortify/github-action/without-artifacts
    Run OpenText AST scans without uploading debug artifacts; use this sub-action to implement a custom artifact upload mechanism.

  • fortify/github-action/setup
    Bootstrap fcli and Fortify tools for custom CI/CD workflows.
