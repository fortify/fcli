Name

fcli-fod-mast-scan - Manage FoD MAST scans.

Synopsis

fcli fod mast-scan [-h] [COMMAND]

Description

Generic fcli options (also see documentation link below)

-h, --help

Use 'fcli [command] -h' to display help for fcli (sub-)commands.

Commands

cancel

Cancel a MAST scan.

download

Download scan results.

download-latest

Download latest scan results from release.

get

Get MAST scan details.

get-config

Get current MAST scan configuration.

import

Import existing MAST scan results (from an FPR file).

list, ls

List MAST scans.

setup

Configure MAST scan details for the release.

start

Start a new MAST scan.

wait-for

Wait for one or more MAST scans to reach or exit specified scan statuses.
